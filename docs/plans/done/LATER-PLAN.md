# 하위 할 일 "나중에(프로젝트로)" 계획

작성 2026-09-30. 시안: https://claude.ai/artifact/4ydwEuprX4JdD8yDsEc9G5 (① 마우스를 올리면 · ② 누른 직후 · ③ PARA 할 일 탭)

> **상태: 시안 컨펌(글자 + 아이콘, 옮김 표시 남김) → 구현.**

## 1. 왜

업무 블록의 하위 할 일에는 "오늘 꼭 끝낼 일"과 "시간 될 때 하는 롱텀 업무"가 섞여 있다. 롱텀 업무가 하위 할 일에 남아 있으면
매일 넘김(CARRY-OVER-PLAN.md)으로 쌓이고 진행률도 늘 `0/6`이라, 넘김 기록이 "못 한 일"이 아니라 소음이 된다.
롱텀 업무는 **프로젝트의 날짜 없는 할 일**로 두고, 할 때가 되면 Inbox에서 캘린더 업무 블록 위로 끌어 놓는다(겹치면 안쪽에 쏙 얹힘).
이미 하위 할 일로 적어둔 걸 그쪽으로 옮기는 입구가 "나중에" 버튼이다.

## 2. 규칙 (2026-09-30 사용자 확정)

| 항목 | 규칙 |
|---|---|
| 버튼 | 하위 할 일 행의 × 왼쪽 **"나중에"**(폴더 아이콘 + 글자 — ×와 헷갈리지 않게). 안 끝난 항목만(완료 · 넘김엔 없음). 데스크톱은 hover, 터치는 늘 보임 |
| 누르면 | 같은 이름의 할 일을 **날짜 없이, 부모 할 일과 같은 PARA**로 만든다(PARA 할 일 탭 · Inbox에 보임). 부모에 PARA가 없으면 Inbox로만 |
| 옮김 표시 | 새 할 일 메모에 `- [[L사 업무(9/30)]]에서 옮김`(부모에 날짜가 없으면 `- [[L사 업무]]에서 옮김`) — 누르면 원래 할 일로(2026-10-01 LINKS-PLAN.md. 처음엔 링크 없는 `L사 업무(9/30)에서 옮김`이었고, 그 메모도 링크로 읽는다) |
| 원래 항목 | 하위 할 일에서 **지운다**(넘김 기록 안 남김 — 못 한 게 아니라 나중에 할 일로 분류한 것) |
| 되돌리기 | 화면 아래 알림 "EAI Event Call 테스트 → 2026 L사 할 일로 보냈어요 · 되돌리기" 5초. 누르면 새 할 일을 지우고 하위 할 일을 같은 순서 자리에 다시 만든다 |

## 3. 구현

- `useTodoActions().moveSubtaskToLater(subtaskId)` — 할 일 만들기(메모 포함, `NewItemFields.memo`) → 하위 할 일 삭제 → 되돌리기 함수 반환.
- `components/subtask/subtask-list.tsx` — 행의 "나중에" 버튼 · 알림(`LaterToast`, body 포털). 상세 팝업 · PARA 상세 펼침이 같이 쓴다.
