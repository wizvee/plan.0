## 1. 왜

사용자가 "나중에"(LATER-PLAN.md)를 새 할 일 만들기로만 쓰지 않고, **회의에서 나온 할 일을 일부러 회의 할 일의 하위 할 일로 적은 뒤
"나중에"를 눌러** "어느 회의에서 파생됐는지" 남기고 있다. 그런데 메모의 `회의(10/1)에서 옮김`은 글자뿐이라 그 회의로 갈 수 없고,
"나중에"는 하위 할 일을 지우므로 **회의 쪽에선 무엇이 나갔는지 사라진다**.

## 2. 규칙 (2026-10-01 사용자 확정 — 추천안 1~4)

| 항목 | 규칙 |
|---|---|
| ① 형식 | "나중에" 메모 = `- [[`RESP_DIV_TAB` 회의(10/1)]]에서 옮김` — 옵시디언 내부 링크. `[[ ]]` 안은 **할 일 이름 + `(M/d)`**(이름이 매일 반복되니 날짜로 구분, 날짜 없으면 이름만). "에서 옮김"은 괄호 밖 — 안쪽이 정확히 대상 이름이어야 옵시디언(노트로 전환 → Drive .md)에서도 링크로 맞는다 |
| 찾기 | 같은 이름 + 같은 월/일인 할 일. 여럿이면 링크를 쓴 할 일이 만들어진 날 이전에서 가장 가까운 것. 자기 자신은 뺀다. DB 변경 없음 |
| 보기 | 메모 보기 모드에서 파란 글자(hover 밑줄, 툴팁 "10월 1일 (수) — 누르면 열기"). 누르면 **그 할 일 팝업이 위에 겹쳐 열리고** 닫으면 돌아온다. 원문은 메모를 누르면 그대로 보인다 |
| ④ 끊긴 링크 | 원래 할 일을 지웠거나 못 찾으면 회색 점선 밑줄 + "원래 할 일을 찾을 수 없어요", 누를 동작 없음 |
| 직접 쓰기 | 메모 아무 데나 `[[이름]]` · `[[이름(10/1)]]` · `[[이름|보이는 글자]]`를 쳐도 링크(표시 줄 안에서도) |
| ② 옮긴 할 일 목록 | 원래 할 일 팝업 하위 할 일 탭, 체크리스트 아래 **"나중에로 옮긴 할 일 N"** — 메모의 "…에서 옮김" 줄이 이 할 일을 가리키는 할 일들(역링크). 상태(완료 = 카테고리 색 체크 + 취소선) · 날짜(없으면 "날짜 없음"), 누르면 그 할 일. 진행률에 넣지 않음. 없으면 숨김. 링크로 연 원래 할 일은 이 목록이 보이는 하위 할 일 탭으로 열린다 |
| ③ 이름 · 날짜 바뀜 | 할 일 이름을 바꾸거나 다른 날로 옮기면(드래그 · Inbox로 빼기 · 노트 전환 포함) 그 할 일을 가리키던 다른 메모의 링크도 새 대상으로 고친다(옵시디언처럼). 별칭(`|…`)은 남김 |
| ④ 예전 메모 | 이미 저장된 `L사 업무(9/30)에서 옮김`(괄호 없음)은 **원문을 바꾸지 않고** 표시 없는 줄 전체가 "…에서 옮김"이면 찾아지는 경우에만 링크로 보여준다(못 찾으면 보통 글자). 옮긴 할 일 목록 · 이름 바뀜 고치기에도 포함(고칠 땐 예전 모양 그대로 이름만) |
| 검색 | 검색 결과의 메모 줄은 괄호를 떼고 `회의(10/1)에서 옮김`으로 |
